
# Configuration Files

This directory contains example configuration files and documentation for the services running in my home lab.

> **Note:** Sensitive information such as passwords, API keys, and private certificates are never committed to this repository. Configuration files containing secrets are replaced with `.example` versions.

## Files

| File | Purpose |
|------|---------|
| `docker-compose.example.yml` | Example Docker Compose stack |
| `jellyfin.env.example` | Example Jellyfin environment variables |
| `qbittorrent.env.example` | Example qBittorrent environment variables |
| `samba.conf.example` | Example Samba configuration |
| `tailscale-notes.md` | Notes from configuring Tailscale |
| `network-settings.md` | Local network configuration and addressing |configs/
