# Infrastructure Diagrams

This directory contains architecture diagrams documenting the design, networking, and data flow of my home lab.

These diagrams are updated as the environment evolves and are intended to provide a visual reference for system architecture, networking, storage, and service relationships.

## Diagrams

| Diagram | Description |
|---------|-------------|
| `homelab-overview.drawio` | High-level overview of the home lab architecture |
| `network-topology.drawio` | Physical and logical network layout |
| `docker-architecture.drawio` | Docker containers and service relationships |
| `media-server-flow.drawio` | Media request and streaming workflow |
| `storage-layout.drawio` | Storage volumes and directory structure |
| `remote-access.drawio` | Secure remote access architecture using Tailscale |
| `backup-strategy.drawio` | Backup and disaster recovery workflow |
| `README.md` | Documentation for this directory |

## Software

Diagrams are created using draw.io (diagrams.net) and may also be exported as PNG files for documentation.
